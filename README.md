# Privacidad y soporte de las apps

Las dos páginas que Apple exige a cada app de la fábrica: privacidad y soporte.
No es una web: solo texto, sin analítica ni nada que se descargue de fuera.
Se publican con GitHub Pages en https://albertodlrc2006-droid.github.io/

Una carpeta por app: `<app>/privacidad/index.html` y `<app>/soporte/index.html`,
con `estilo.css` común. Al añadir una app, enlázala también en `index.html`.
